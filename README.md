## 🎯 快速开始

1. **第一次玩**：先看 `guides/beginner/01-基础介绍.md` 和 `02-新手开局指南.md`
2. **和朋友联机**：直接看 `multiplayer/局域网联机指南.md`

## ⚡ 快速备忘（玩的时候最容易忘的几件事）

| 想做的事 | 怎么做 |
|---------|--------|
| 展开基地 / 采矿车卸货 | 选中后按 **F**（Deploy） |
| 跳回基地视角 | **H**（Cycle Base） |
| 跳到最近的事件/警报处 | **空格**（To Last Event） |
| 跳到当前选中的单位 | **Home**（To Selection） |
| 部队边走边打 | **A** 攻击移动（Attack Move） |
| 躲炮击/核弹 | **Ctrl+X** 散开（Scatter） |
| 保存游戏（仅单人） | **Esc** → Save Game |
| 找到所有采矿车 | **N**（Cycle Harvesters） |

## 💡 核心理念

- **先活下去，再谈发展**：RA 里快攻是常态，前几分钟的防守决定整局
- **电力是心跳**：缺电 = 生产变慢 + 防御失效，宁可多造一个发电厂
- **经济是弹药**：采矿车就是命脉，杀对方矿车比杀坦克更赚
- **两个人一起玩更热闹**：3v3 打 AI 比单挑有意思得多，团队战是本仓库的重点玩法
