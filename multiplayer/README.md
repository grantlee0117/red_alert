## 联机三要素（排障先看这三个）

1. **版本一致**：双方 OpenRA 版本必须相同（主界面右上角可见，如 release-20250330）
2. **网络可达**：局域网=同一网段；公网=端口转发或虚拟局域网
3. **防火墙放行**：Windows 第一次建房弹窗要点"允许"

## 联机模式的限制

- **不能存档、不能暂停**：联机局是双方实时同步的，Esc 菜单里没有 Save
- 断线的玩家会掉出对局，无法中途重连（重开一局吧）
