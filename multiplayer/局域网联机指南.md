# 红色警戒 — 局域网联机指南

> 适用场景：两台电脑连**同一个路由器 / 同一个手机热点**（人在一处）。
> 异地联机的朋友请直接跳到文末「不在同一局域网怎么办」。

场景很简单：谁当**房主**先商量好——建议配置好、网络稳的那台当房主，另一台做客机。

---

# 第一部分：房主操作

## 第 1 步：建房

主菜单 → **Multiplayer** → **Create Server**，起个房间名（可设密码），建好后自动进入战局大厅。

## 第 2 步：查自己的局域网 IP

`Win + R` → 输入 `cmd` 回车 → 输入：

```
ipconfig
```

找到 **IPv4 地址**，一般是 `192.168.x.x` 或 `172.20.10.x` 这种格式（例如 `192.168.1.100`）。把它告诉朋友。

## 第 3 步：在大厅等

- 选好地图（建议人多图，比如 Europe 10 人图）、加好 AI、定好 Team
- 等朋友进来，双方 Ready 后点 **Start Game**

---

# 第二部分：客机操作

## 第 4 步：直连

主菜单 → **Multiplayer** → **Direct Connect**，输入房主 IP：

```
192.168.1.100:1234
```

- `1234` 是 OpenRA 默认端口，房主没改过就填这个
- 连上后进入房主的大厅，选颜色/阵营、点 Ready 等开局

> 💡 有些版本的 Multiplayer 服务器列表会自动显示局域网内的房间，可以先找找看；**Direct Connect 直连是百分百可行的兜底方案**。

## 第 5 步：开打

开局后联机**不能存档不能暂停**，Esc 菜单里没有 Save——这是正常限制，不是坏了。

---

# 第三部分：连不上怎么办（按顺序排查）

## 排查 1：防火墙（最常见）

房主第一次建房时，Windows 弹窗"是否允许 OpenRA 访问网络"必须点**允许**（勾选"专用网络"）。

当时点了拒绝的修复方法：Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙 → 找到 OpenRA → 勾上"专用"和"公用"。

## 排查 2：确认真的在同一网段

两人分别 `ipconfig`，IP 前三段应一致（都是 `192.168.1.x`）。不一致说明连的不是同一路由器/热点——连同一个 WiFi 或热点再来。

## 排查 3：先 ping 通

客机上 `Win + R` → `cmd` → 执行：

```
ping 房主的IP
```

- ✅ 有回复 → 网络没问题，回头检查防火墙和 IP:端口填写
- ❌ 全部超时 → 网络层不通：关掉加速器/VPN（虚拟网卡会干扰），确认连的同一个热点

## 排查 4：版本一致

主界面右上角有版本号（如 `release-20250330`）。版本不同的双方进不了同一个房——都去官网下同一版本。

# 第四部分：关于那两条黄色提示

建房时聊天区会出现：

- **"Server port is not accessible from the internet"** — 你的端口从公网访问不了（路由器没做端口转发）。意思是**互联网上的陌生人加不进你的房**。对局域网联机**毫无影响**，你们走的是内网直连。
- **"Game has not been advertised online"** — 房间没有发布到公共在线列表，外网玩家看不到。同样不影响局域网。

这两条可以理解为"你的房间是私密房"，对局域网玩法反而是好事。只有想让外地网友加入时，才需要下面的方案。

---

# 第五部分：不在同一局域网怎么办

三个方案，从易到难：

1. **虚拟局域网工具（推荐）**：两边都装 [ZeroTier](https://www.zerotier.com/) 或 Tailscale 或 Radmin VPN，加入同一个虚拟网络后，各自拿到一个虚拟 IP，之后完全按本文的局域网流程操作（Direct Connect 那个 IP 换成虚拟 IP 即可）。
2. **直连在线大厅**：如果只是想一起打 AI 或跟别人对战，双方各自从 Multiplayer 浏览官方在线服务器，进同一个房间就行（无需任何内网配置）。
3. **路由器端口转发**：在房主路由器上把 UDP 1234 端口转发到房主电脑，再把公网 IP 给朋友——最折腾，有了 ZeroTier 就别选这个。
