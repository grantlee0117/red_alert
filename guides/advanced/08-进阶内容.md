# 红色警戒 — 进阶内容

> 单机练熟、联机不怯场之后，这份进阶指南帮你把胜率再抬一档。

---

## 一、开局套路

### 快攻 Rush（5 分钟内终结对手）

1. 电厂 → 兵营 → 出步枪兵，攒 5~8 个直接压到敌方基地门口
2. 兵营放在己方前线一侧，缩短出兵路程
3. 配 1~2 个火箭兵拆对方的精炼厂/矿车
4. 目标不是打死对面，是**打断采矿**，逼他回防亏经济

### 发展 Boom（经济碾压流）

1. 标准开局后立刻补第 2 辆矿车，再补第 2 座精炼厂
2. 双战车工厂并行出坦克，雷达 → 科技中心不省
3. 用防御塔+少量坦克守到坦克群成型
4. 10 辆中坦/重坦一起出门，一波带走

### 每局先问自己三个问题

- 对面是什么阵营？（苏军快攻猛，盟军中期强）
- 图大图小？（小图必防快攻，大图必抢第二矿区）
- 有水吗？（有水早补船坞，海军是白赚的优势）

## 二、微操进阶

- **集火点名**：右键点对面矿车/精炼厂，全队齐射单体，切勿让 AI 自由分配火力
- **残血拉回**：快死的坦克往后拖，让对面齐射落空，再拉回前排继续输出（红警单位不会自愈，回血靠维修厂或机械师）
- **W 同类选择**：混战里只挑坦克拉走，步兵断后
- **A 攻击移动** 探路：部队推进永远带 A，路过草丛自动清狗
- **空格键巡逻警报**：多线作战时听到"EVA 警报"先按空格定位，再决定回不回防
- **维修厂运用**：残血坦克撤回 Service Depot $1200 修满再战，部队越打越强

## 三、空中与海战要点

- **盟军空军线**：直升机坪 $500 → 黑鹰 $1500（机炮扫步兵）→ 长弓 $2000（火箭点坦克，需要科技中心）
- **苏军空军线**：机场 $500 → Yak $1350（扫步兵）→ 米格 $2000（火箭重创坦克，需要科技中心）
- 飞机自动出击自动返航装弹，但会被防空打；进攻前先清掉对方 SAM/防空炮
- **海军是单点突破利器**：巡洋舰 $2400 站在海岸线上能把大半个基地轰平，对岸没有反制就是死刑
- 反潜：盟军驱逐舰（深水炸弹）、苏军用直升机；看见对面潜坞，沿海放反潜单位

## 四、超级武器攻防

| 场景 | 做法 |
|-----|------|
| 苏军核弹来了 | 警报响 → 找到红圈 → **Ctrl+X 散开** + 坦克拉开，别心疼那一个建筑 |
| 对面有铁幕 | 铁幕套无敌的猛犸冲塔时，用数量换：无敌只有几十秒，拖过去再围殴 |
| 对面是德国 | 永远留一支预备队在基地深处，防超时空偷袭 |
| 对面 GPS 点亮 | 假设行动全被看穿，用佯攻骗调动 |
| 自己的超级武器 | 造在基地最深处；核弹留着炸对方战车工厂群，别砸前线兵 |

## 五、多线运营（联机/大图核心）

1. **第二矿区**：第一矿区枯竭前 2 分钟就该派 MCV 出发，别等矿车原地发呆
2. **前线基地**：分基地=兵营+战车工厂+防御塔，出兵路程缩短一半
3. **多兵线**：2 个战车工厂并行出坦克；钱多到花不完就再加
4. **部队轮换**：前线打残的队撤回来维修，满编队顶上——部队是要养的资产
5. **地图控制**：中场矿区和路口用防御塔+坦克驻守，把战场钉死在对方半场

## 六、录像与复盘

- 所有对局自动保存在录像里：`AppData\Roaming\OpenRA\Replays`
- 主菜单 → Extras 可观看回放（支持观战视角、快进）
- 输了的对局回放看三件事：第一波交火输在哪、矿车死了几辆、钱在什么时候断流的

## 七、版本与地图资源

- 本仓库数值基于 **release-20250330**；OpenRA 每次大版本都会平衡性调整，出勤表可能变化
