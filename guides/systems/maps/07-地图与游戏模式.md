# 红色警戒 — 地图与游戏模式

> 选对地图 = 赢在开局。本篇讲选图界面、官方图推荐和战局大厅 Options 的每一项。

---

## 一、游戏模式

| 模式 | 规则 |
|-----|------|
| **Conquest 征服**（主流） | 消灭所有敌方单位与建筑；这也是 Skirmish 的默认模式 |
| Missions 战役 | 单人剧情任务（主菜单 Singleplayer → Missions） |

多人玩法全部基于 Conquest：1v1 决斗、FFA 大乱斗（Team 全设 "-"）、团战（Team 分组）都由大厅配置决定。

---

## 二、选图界面怎么用

Choose Map 界面各控件：

- **缩略图上的 A/B/C… 圆标** = 出生点位，大厅里 Spawn 列可以锁定或随机
- **Filter** 按名字搜图
- **All Maps (83)** 下拉筛选地图来源（官方/自制）
- **Order by** 排序（按人数/名字等）
- **Random Map** 随机选一张
- 地图名称下方标注：模式、人数、尺寸（如 71x70 Medium / 110x90 Large）

> 💡 预览图显示阵营徽章占位符 = 该图预览还没下载完成，不影响游玩。

## 三、官方地图推荐（按场景）

| 场景 | 推荐地图 | 理由 |
|-----|---------|------|
| 新手第一局 | **Desert Rats**（2人, 71x70） | 最小的官方 1v1 图，无水域无花活，节奏快重开快 |
| 单挑进阶 | **Discovery**（2人, 91x81） | 大一档，有发育空间，快攻容错更高 |
| 想练海军 | **Dual Cold Front**（2人, 110x90） | 有大片水域，海陆空俱全 |
| 2v2 / 3v3 团战 | **Fort Lonestar**（4人） | 中心要地必争，攻防转换热闹 |
| 大混战 | **Tribute**（8人） | 经典 8 人图，地形多样，FFA 和团战皆宜 |
| 海陆空大乱炖 | **Pool Party**（8人） | 水域极多的大图，最"丰富"，但需要会海战 |
| 10 人超级大图 | **Europe**（10人） | 欧洲地图，A~J 十个出生点，多人局天花板 |

选图原则：**人多选大图，人少选小图**；想玩海军先确认图上有水；出生点距离决定快攻强度。

## 四、战局大厅 Options 全解（默认值）

这些选项所有人进房都能看到，房主决定最终值（默认值即遭遇战默认配置）：

| 选项 | 默认 | 含义 |
|-----|------|------|
| Starting Cash 初始资金 | **$5000** | 开局资金，调高=和平发育局 |
| Tech Level 科技等级 | **Unrestricted** | 解锁上限：仅步兵/低/中/无超级武器/无限制 |
| Short Game 短局模式 | **开** | 拆光主要建筑即判负，不用追杀最后一个工程师 |
| Fog of War 战争迷雾 | **开** | 未探索区域不可见（关了就是全图亮） |
| Explored Map 已探索地图 | **关** | 开局是否直接点亮全图地形 |
| Crates 补给箱 | **开** | 地图随机刷箱子，捡了随机获得奖励/诅咒 |
| Build Radius 建造范围 | **开** | 建筑只能放在现有建筑旁边（关了可全图造） |
| Build Ally 盟友代建 | **开** | 盟友可以帮你在他的范围内放建筑 |
| MCV Redeploy 建造厂收回 | **开** | 建造厂可收回成 MCV 搬家 |
| Reusable Engineers 工程师可复用 | **关** | 开启后工程师占领建筑后存活（默认会进入建筑消失） |
| Kill Bounties 击杀赏金 | **关** | 击杀敌方单位获得其造价比例的赏金 |
| Game Speed 游戏速度 | **default** | 常规节奏；调慢更适合新手盘 |
| Time Limit 时间上限 | **0（无限制）** | 到时间按分数判胜负 |
| Separate Team Spawns 队友分开出生 | **开** | 关闭时同队会挤在相邻出生点 |

> 💡 新手局推荐改三项：初始资金调 $10000、AI 换 Turtle、Speed 调慢——体验完整流程再回归默认。

---

## 五、Handicap 让手

大厅里每人的 Handicap 列（默认 0%）是给高水平玩家的减益开关。带新手入坑时，老玩家给自己调 Handicap，比让 AI 数量失衡更优雅。
