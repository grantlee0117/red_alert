# 红色警戒 — 操作与快捷键

> 以下全部为 **Modern 控制方案** 的默认键位（release-20250330 官方数据），可在 Settings → Hotkeys 里改。完整表格见 [[快捷键速查|wiki：快捷键速查]]。

---

## 一、界面布局

| 区域 | 内容 |
|-----|------|
| **右侧面板** | 上方：阵营徽章、资金 $、游戏时间、电力 ⚡；下方：生产面板 |
| **生产面板左侧竖排 6 个页签** | 建筑 Buildings(E) / 防御 Defense(R) / 步兵 Infantry(T) / 载具 Vehicles(Y) / 飞机 Aircraft(U) / 海军 Naval(I) |
| **左下角指令栏** | 左半：命令按钮（攻击移动 Attack Move / 停止 Stop / 散开 Scatter / 部署 Deploy…）；右半：开火姿态 Stances |
| **左上角** | 雷达小地图（造出雷达球 Radar Dome 后点亮），点哪里视角跳哪里 |
| **右上角齿轮 / Esc** | 菜单：暂停、存档（仅单人）、设置、投降 |

生产面板读法：图标变暗=前置不满足或电力不足；图标闪烁=造好了等你放置；点击建造中的图标=暂停；右键=取消。

## 二、必背的十个键

| 键 | 功能 |
|----|------|
| **F** | 部署 Deploy：MCV 展开、采矿车卸货 |
| **A** | 攻击移动 Attack Move：边走边打 |
| **S** | 停止 Stop |
| **Ctrl+X** | 散开 Scatter（躲炮击/V2/核弹的保命键；单按 X 是"断电模式 Power Down"，别按错） |
| **H** | 在你的各处基地间循环跳转（Cycle Base） |
| **空格** | 跳到最近的事件/警报处（To Last Event） |
| **Home** | 跳到当前选中的单位（To Selection） |
| **N** | 在各采矿车之间循环跳转（Cycle Harvesters） |
| **Ctrl+数字** | 编队（Control Groups）/ 数字键选中 |
| **Esc** | 菜单（暂停/存档/投降 Surrender） |

> ⚠️ 注意两个容易记混的：**Z 是变卖建筑**（回收换钱），**C 是修理建筑**，都不是单位命令。

---

## 三、选择与编队

| 键 | 功能 |
|----|------|
| Q | 选中全地图所有作战单位（Select All Units） |
| W | 选中屏内所有同类型单位（Select Units By Type，点一辆坦克按 W = 全选坦克） |
| Shift+点击 | 增减选中的单位 |
| Ctrl+数字 | 把当前选中单位编为该队 |
| 数字 | 选中该队（连按两次跳到队伍处） |

---

## 四、视角控制

| 操作 | 效果 |
|-----|------|
| 鼠标移到屏幕边缘 / 方向键 | 平移视角 |
| 滚轮 | 缩放 |
| `[` / `]` | 缩小 / 放大 |
| `.` | 重置缩放 |
| **Ctrl+Q/W/E/R** | 把当前视角存为书签 1~4 |
| **Alt+Q/W/E/R** | 跳回书签 |
| Alt+方向键 | 直接跳到地图对应边缘 |

> 💡 视角书签实战：把主战场设为书签 1（Ctrl+W），基地设为书签 2（Ctrl+E），前线基地之间瞬间切换。

---

## 五、经济与建筑快捷键

| 键 | 功能 |
|----|------|
| **Z** | 变卖模式 Sell：点建筑回收换钱（回收价约为造价一半） |
| **C** | 修理模式 Repair：点建筑开始维修（持续花钱） |
| **X** | 断电模式 Power Down：点建筑让它临时下线（微调电力用，极少用到） |
| **B** | 放置信标 Place Beacon：联机时给队友标记位置 |
| **Ctrl+Tab** | 在各生产建筑间循环切换出兵点（Cycle Production Buildings） |
| E/R/T/Y/U/I | 直接切到 建筑 Buildings/防御 Defense/步兵 Infantry/载具 Vehicles/飞机 Aircraft/海军 Naval 生产页签 |

---

## 六、音乐与杂项

| 键 | 功能 |
|----|------|
| M | 静音（Toggle Mute） |
| Pause | 暂停（Pause） |
| Ctrl+P | 截图（Screenshot） |
| `,` | 循环切换血条显示模式（Cycle Status Bars） |
