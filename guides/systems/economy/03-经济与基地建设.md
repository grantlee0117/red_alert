# 红色警戒 — 经济与基地建设

> 红警的经济只有一条主线：**金矿 → 采矿车 → 精炼厂 → 资金**。基地建设则是围绕这条主线搭建生产与防御体系。

---

## 一、电力系统

| 状态 | 后果 |
|-----|------|
| 电力盈余 | 一切正常 |
| **电力不足** | 所有生产（建筑+单位）时间 **×3**、雷达/高级防御/超级武器直接停机 |

### 结算方式

右上角的数字 = **总发电量 − 总耗电量**。≥0 正常，<0 进入低电力状态，直到你拆建筑、断电（X）或补发电厂。

> 💡 电力是**全局结算**：没有电线、没有输电距离、没有局部供电的概念。发电厂放基地最深处，地图另一头的特斯拉线圈照样满功率运转。唯一和距离有关的是"建造范围"（见下文），不是电力。

### 发电

| 建筑 | 发电 |
|-----|------|
| 发电厂 Power Plant | +100 |
| 高级发电厂 Adv. Power Plant | +200 |

> ⚠️ **发电厂会随血量减产**：被打到半血的发电厂只发一半电。挨炸的电厂要么修，要么当它已经没了。

### 耗电一览（release-20250330）

| 建筑 | 耗电 | 建筑 | 耗电 |
|-----|------|-----|------|
| 盟军科技中心 Allied Tech Center | -200 | 战车工厂 War Factory | -30 |
| 铁幕装置 Iron Curtain | -200 | 维修厂 Service Depot | -30 |
| 超时空装置 Chronosphere | -200 | 苏军兵营 Soviet Barracks | -20 |
| 核弹发射井 Missile Silo | -150 | 机场 Airfield | -20 |
| 特斯拉线圈 Tesla Coil | -80 | 火焰塔 Flame Tower | -20 |
| 间隙发生器 Gap Generator | -60 | 碉堡 Pillbox / 迷彩碉堡 Camo Pillbox | -20 |
| 防空炮 AA Gun | -50 | 船坞 Naval Yard | -20 |
| 雷达球 Radar Dome | -40 | 直升机坪 Helipad | -10 |
| 炮塔 Turret | -40 | 矿石仓 Silo | -10 |
| SAM Site | -40 | 狗窝 Kennel | -10 |
| 矿石精炼厂 Ore Refinery | -30 | **盟军兵营 Allied Barracks / 潜艇坞 Sub Pen** | **0** |

### 低电力时谁会停机

- **停机**：特斯拉线圈、防空炮、SAM、雷达球（小地图）、间隙发生器、核弹井、铁幕、超时空、盟军科技中心（GPS）
- **照常开火**：炮塔、火焰塔、碉堡——它们耗电，但不依赖电力开火

### 套用到开局

电厂 +100；精炼厂 -30、战车工厂 -30、雷达 -40：苏军兵营 -20，造完雷达刚好转负 → **这就是"造完雷达补电厂"的由来**。盟军兵营 0 耗电，压力稍小，但上科技中心（-200）前请先囤两个电厂。

### 快速诊断

- 特斯拉线圈 -80 ≈ 一座电厂专门喂它：线圈阵 = 电厂阵
- 盟军科技中心 -200 是全游戏最大电老虎，造之前先看右上角余量

## 二、采矿经济

### 核心循环

```
金矿 → 采矿车(Ore Truck $1100) 采集 → 矿石精炼厂(Ore Refinery $1400) 卸货换钱
```

- 精炼厂**自带一辆采矿车**，所以第一座精炼厂 = $1400 买到完整经济单元
- 精炼厂自带少量储存容量；存满了钱进不来，可补**矿石仓 Silo $150**（后期钱多到溢出时才需要）
- 第二辆矿车从**战车工厂**补，$1100，尽早补——经济决定暴兵速度
- 矿车是全游戏最值得保护的单位：**杀对方一辆矿车比杀两辆坦克更赚**
- 矿会采完，大图中期要往新矿区扩张（见下文分基地）

### 经济健康检查

| 信号 | 诊断 |
|-----|------|
| 钱长期低于几百 | 矿车不够或矿快没了，补矿车/扩张 |
| 精炼厂门口排队的矿车 | 精炼厂不够，再建一座 |
| 钱常年上万花不掉 | 兵线产能不足，补战车工厂（多兵线可并行出兵） |

## 三、建筑生产规则

- 点右侧生产面板的建筑图标 → 进度条 → **图标闪烁时点击它**，再左键选位置放置（绿色=可放）
- 放置位置有两个硬条件：① 在**己方建筑的建造范围**内——建造厂提供 16 格半径的大圆圈，其他绝大多数建筑也各提供一小圈（例外：潜艇坞、船坞、矿石仓、狗窝不提供范围）；② 放置格子必须**已探索**（黑雾里不能放，探索过的灰色区域随时可放，不要求实时视野）
- 水面（除非是船坞类）、悬崖等无效地形同样显示红色不可放
- **建造厂可以再收回成 MCV**（默认开启），让你把基地整个搬家去开分矿
- 同类生产建筑越多，同屏出兵速度越快（多兵线并行）——后期 2~3 个战车工厂是标配

### 科技等级（Tech Level）

战局 Options 里可选，默认 Unrestricted。它决定解锁到哪一档：

| 档位 | 大致范围 |
|-----|---------|
| Infantry Only 仅步兵 | 只有步兵和基础防御 |
| Low 低 | 基础载具、基础防御塔 |
| Medium 中 | 雷达系建筑、飞机、海军、高级发电厂 |
| No Superweapons 无超级武器 | 全部单位，但没有核弹/铁幕/超时空 |
| Unrestricted 无限制 | 全部内容（默认） |

> wiki 各速查表里的 `techlevel` 标记即对应此选项，日常玩 Unrestricted 不用管。

## 四、基地标准布局思路

1. **精炼厂贴矿放**，矿车少跑路就是多赚钱
2. **电厂放内侧**，别让对方一波骑兵就摸到
3. **防御塔卡在基地入口/矿区路口**，不追求围一圈
4. **战车工厂靠前一点**，出兵快；兵营贴前线城市
5. 留出**一格规划空间**给未来的科技中心、超级武器

---

## 五、扩张与分基地

- 中期从战车工厂再造一辆 **MCV $2000**（需要维修厂），开到新矿区按 F 展开
- 分基地 = 更近的矿区 + 前线出兵点，大图后期没有分基地必输
- MCV 很脆，搬家时派坦克护送；落地第一件事是围一圈电厂+防御
