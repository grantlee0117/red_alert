# 红色警戒（OpenRA） — 基础介绍

> OpenRA release-20250330 | 免费开源 | 支持平台：Windows / macOS / Linux | 支持中文

---

## 游戏是什么？

《红色警戒》（Red Alert）是 1996 年 Westwood 出品的经典即时战略（RTS）游戏，**OpenRA** 则是社区用开源引擎对它做的现代化重制：画面原汁原味，但加入了现代 RTS 的操作习惯（右键下令、单位自动寻找射位、存档回放等），并自带联机大厅。

- **完全免费**，无内购，去 [openra.net](https://www.openra.net/) 下载一个可执行文件即可运行
- OpenRA 不是一个游戏，而是一个**引擎 + 三个模组**：Red Alert（红警）、Tiberian Dawn（泰伯利亚黎明）、Dune 2000（沙丘 2000），本仓库只玩 Red Alert
- 首次运行需要在主菜单的 **Manage Content** 里下载红警的美术/音乐资源包（引擎本体不含素材）

## 第一次启动：初始化设置向导

首次进入红警模组会弹出 "Establishing Battlefield Control" 设置界面，一次性配置好这几项：

| 选项 | 建议 |
|-----|------|
| **Player Name** | 你的指挥官名字，联机时显示 |
| **Preferred Color** | 涂装颜色，战场上区分敌我 |
| **Control Scheme** | **选 Modern**：左键选择、右键下令，和现代 RTS 一致；Classic 是复刻原版的"左键包办"，新手别选 |
| **Screen Edge Panning** | 勾选（鼠标碰屏幕边缘平移视角，传统 RTS 习惯） |
| **Battlefield Camera** | Medium，同屏视野和单位大小的平衡档 |
| **UI Scale** | 100%，高分屏嫌字小可调大 |
| **Increase Cursor Size** | 高分屏建议勾选，鼠标指针更大更清楚 |

> 💡 以上全部可以在之后的主菜单 **Settings** 里随时改，选错不慌。

## 主菜单速览

| 菜单 | 用途 |
|-----|------|
| **Singleplayer** | 单人游戏：Skirmish 遭遇战（打 AI）、Missions 战役任务、Load 读档 |
| **Multiplayer** | 联机：进在线大厅、自己建房（Create Server）、直连（Direct Connect） |
| **Settings** | 显示/音频/键位等设置 |
| **Extras** | 地图编辑器等附加功能 |
| **Manage Content** | 下载/管理游戏资源包 |
| **Quit** | 退出 |

## 单机和联机的一个重要区别

- **单人遭遇战可以存档**：游戏中按 **Esc** → Save Game，随时暂停随时存
- **联机对局不能存档**：RTS 联机需要双方同步，没有暂停和存档，只能一局打到底

所以练手、实验套路用遭遇战；联机开局前把 [[02-新手开局指南|开局流程]] 先在单机里练熟。

## 每局的基本节奏（RTS 通用模板）

1. **展开基地**：开局唯一的 MCV（Mobile Construction Vehicle 机动建造车）按 F 展开成建造厂（Construction Yard）
2. **经济先行**：发电厂（Power Plant）→ 矿石精炼厂（Ore Refinery），采矿车（Ore Truck）自动采金矿换钱
3. **暴兵防守**：兵营（Barracks）/战车工厂（War Factory）出部队，防住对方第一波快攻
4. **侦查反制**：搞清对方在出什么，出克制兵种
5. **推平对手**：攒出主力部队，端掉敌方基地（Conquest 模式消灭所有敌军建筑与单位即胜）

> ⚠️ 和星露谷式的慢节奏完全不同：红警里前 3 分钟没防守，Rush AI 和真人对手真的会直接把你带走。

## 几个新手常犯的错误

1. **缺电不管** → 生产变慢、防御炮塔失效，看到右上角电力告警立刻补发电厂
2. **矿车被杀不补** → 经济直接断档，矿车是战场上的头号目标
3. **部队右键走位** → 路过敌人不打，推进要用 **A** 攻击移动
4. **只顾采矿不出兵** → 攒了一万块钱没有一辆坦克，被三辆轻坦推平
5. **忘记侦查** → 对方出空军你还在堆坦克，等于白送
6. **联机局想存档** → 联机没有存档，关键操作要平时在单机里练
