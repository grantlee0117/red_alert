# 快捷键速查

> Modern 控制方案的默认键位，来源：release-20250330 官方 hotkeys 数据。游戏内 Settings → Hotkeys 可自定义。

---

## 核心十键（先背这些）

| 键 | 功能 |
|----|------|
| **F** | 部署 Deploy：MCV 展开 / 采矿车卸货 |
| **A** | 攻击移动 Attack Move |
| **S** | 停止 Stop |
| **Ctrl+X** | 散开 Scatter（躲范围攻击） |
| **H** | 在各处基地间循环跳转（Cycle Base） |
| **空格** | 跳到最近的事件/警报处（To Last Event） |
| **Home** | 跳到当前选中单位（To Selection） |
| **N** | 循环跳转采矿车（Cycle Harvesters） |
| **Ctrl+数字** | 编队 Control Groups；数字键选中 |
| **Esc** | 菜单（暂停/存档/投降 Surrender） |

---

## 单位命令

| 键 | 功能 |
|----|------|
| A | 攻击移动 Attack Move |
| S | 停止 Stop |
| Ctrl+X | 散开 Scatter |
| F | 部署 Deploy |
| D | 护卫 Guard（跟随并保护目标） |

> ⚠️ 单按 **X** 是"断电模式"（点建筑临时下线），不是散开。

---

## 开火姿态

| 键 | 姿态 | 行为 |
|----|------|------|
| Alt+A | 主动攻击 Attack Anything | 见敌就打并追击（默认） |
| Alt+S | 防守 Defend | 只打范围内，不追击 |
| Alt+D | 还击 Return Fire | 挨打才还手 |
| Alt+F | 停火 Hold Fire | 永不开火（间谍潜行必备） |

---

## 选择

| 键 | 功能 |
|----|------|
| Q | 选中所有作战单位（Select All Units） |
| W | 选中屏内同类型单位（Select Units By Type） |
| Shift+点击 | 增减选择 |
| Ctrl+数字 / 数字 | 建队 / 选队（Control Groups） |

---

## 视角

| 键 | 功能 |
|----|------|
| 屏幕边缘 / 方向键 | 平移 |
| 滚轮 | 缩放 |
| `[` / `]` / `.` | 缩小 / 放大 / 重置缩放 |
| H | 循环跳转基地 Cycle Base |
| 空格 | 最近事件 To Last Event |
| Home | 选中单位 To Selection |
| N | 循环采矿车 Cycle Harvesters |
| Ctrl+Q/W/E/R | 保存视角书签 Map Bookmarks 1~4 |
| Alt+Q/W/E/R | 跳回视角书签 |
| Alt+方向键 | 跳到地图边缘 |

---

## 建筑与经济

| 键 | 功能 |
|----|------|
| Z | 变卖模式 Sell（回收建筑换钱） |
| C | 修理模式 Repair（修建筑） |
| X | 断电模式 Power Down（建筑临时下线） |
| B | 放置信标 Place Beacon（联机标记） |
| Ctrl+Tab | 循环切换出兵的生产建筑（Cycle Production Buildings） |
