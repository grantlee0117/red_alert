# 游戏设置速查

> 战局大厅（Skirmish / 多人建房）里 **Options** 页签的每一项含义，默认值为遭遇战出厂设置（release-20250330）。

---

## 经济与节奏

| 选项 | 默认 | 含义 |
|-----|------|------|
| Starting Cash 初始资金 | **$5000** | 开局资金。调到 $10000+ 适合练习流程的休闲局 |
| Tech Level 科技等级 | **Unrestricted** | 解锁上限：仅步兵 → 低 → 中 → 无超级武器 → 无限制 |
| Game Speed 游戏速度 | **Default** | 整体节奏快慢，新手盘可调慢 |
| Time Limit 时间上限 | **0** | 0 = 无限制；设了时间到按分数判胜负 |
| Handicap 让手 | **0%** | 给强者的减益，带新人时老玩家给自己开 |

## 地图与视野

| 选项 | 默认 | 含义 |
|-----|------|------|
| Fog of War 战争迷雾 | **开** | 关闭则全图常亮（练习局可关） |
| Explored Map 已探索地图 | **关** | 开启后地形开局可见（单位仍需视野） |
| Crates 补给箱 | **开** | 随机刷新箱子：可能捡钱、单位，也可能中诅咒 |

## 规则开关

| 选项 | 默认 | 含义 |
|-----|------|------|
| Short Game 短局 | **开** | 摧毁对方关键建筑即获胜，不必清光每个单位 |
| Build Radius 建造范围 | **开** | 建筑须放在现有建筑旁；关闭=全图任意放置（大幅改变玩法） |
| MCV Redeploy 建造厂收回 | **开** | 建造厂可收回成 MCV 搬家开分矿 |
| Reusable Engineers 工程师复用 | **关** | 默认工程师占领建筑后会消失；开启则保留 |
| Kill Bounties 击杀赏金 | **关** | 开启后击杀单位按造价比例返现，鼓励进攻 |
| Ally Build 盟友代建 | **开** | 盟友可在你的建造范围内帮你放建筑 |
| Separate Team Spawns 队友分离出生 | **开** | 关闭时同队出生点挤在一起 |

---

## 大厅其他列的含义

| 列 | 含义 |
|----|------|
| Name | 玩家/AI；空槽下拉可加 AI 或关闭 |
| Color | 涂装颜色（战场上区分敌我） |
| Faction | 阵营：Any=随机，可选具体国家拿专属单位 |
| Team | 组队编号，同号一队；"-"=混战 |
| Handicap | 让手减益 |
| Spawn | 出生点位（地图上 A、B、C…），"-"=随机 |
| Ready | 准备就绪；联机房全员勾选才能开（房主可直接 Start） |

## AI 类型

| AI | 行为 |
|----|------|
| **Rush AI** | 快攻型，前期就来压制，默认对手 |
| **Normal AI** | 均衡发展，全面威胁 |
| **Turtle AI** | 龟缩型，固守基地，几乎不主动进攻（练运营用） |
| **Naval AI** | 偏爱海军，有水的图上选它才有意义 |

> 💡 无水地图选 Naval AI 会限制它的发挥——想轻松局可以故意在小旱图放 Naval AI。
